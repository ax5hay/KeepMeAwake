# Contributing

Keep me awake is a personal project under its own [license](LICENSE), not an
open-source one. Fixes, bug reports and ideas are welcome all the same.

| You want to               | Do                                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------------- |
| report a bug              | open an issue with the bug template: OS, version, what you did, what happened               |
| suggest a feature         | open an issue with the feature template; the [roadmap](docs/roadmap.md) may already have it |
| report a security problem | see [SECURITY.md](SECURITY.md); please not in a public issue                                |
| send a fix                | open a pull request; the template has the checklist                                         |

Before a pull request: read [`docs/development.md`](docs/development.md) for
setup on Windows or macOS and the house style, keep commits small and in
Conventional Commits form, and run `npm run verify`. One rule is not up for
discussion: the app never sends synthetic input to other applications (see
[ADR 0002](docs/adr/0002-power-requests.md)).

By sending a change you confirm it is yours to give, and that Akshay may use,
change and publish it as part of Keep me awake under any terms he chooses.
