# Security

Keep me awake runs as you, never elevated, makes no network connections and
sends no input to other apps. What it does touch is small: one power request
(Windows) or two power assertions (macOS), a settings file and a log. The
[architecture doc](docs/architecture.md#security-posture) has the full
posture.

## Reporting a problem

If you find something that looks like a vulnerability, please report it
privately through
[GitHub's private advisory form](https://github.com/ax5hay/KeepMeAwake/security/advisories/new)
rather than in a public issue. Say what you found, on which OS and version,
and how to reproduce it. I'll reply as soon as I can; this is a personal
project, so there is no formal response window.

## Supported versions

Only the latest release gets fixes.
